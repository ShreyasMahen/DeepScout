# DeepScout

DeepScout is a self-verifying AI research engine that performs multi-step research, retrieves evidence, detects conflicting information, verifies generated claims, and produces citation-grounded research reports.

## Status

Currently under development.

## Planned Architecture

- Next.js frontend
- FastAPI backend
- PostgreSQL
- pgvector
- LLM-powered research agents
- Retrieval-augmented generation
- Claim verification
- Conflict detection
- Automated evaluation
